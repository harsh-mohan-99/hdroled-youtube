# Contributing

Keep HDROLED YouTube-only, local and free of system-setting access or remote runtime dependencies.

1. Explain the affected edition, browser and playback scenario.
2. Make a focused change with a meaningful behavior test.
3. Run `npm test` and `python scripts/package.py`.
4. Test playback, sound activation, Original, navigation and fullscreen manually. Report what you actually tested.
5. Distinguish configured gain/effect levels from measured loudness or performance. Never promise voice isolation, real HDR or zero resource usage.
6. Use matching paused frames for screenshots; remove private data and retain media attribution.

Do not commit credentials, browser profiles, PC helpers, personal backups or account data.
