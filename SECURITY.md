# Security

The extension should require only local storage and static YouTube content-script access. Changes requesting microphone, capture, all-sites or operating-system permissions need a clear new design review.

Do not post credentials, cookies or personal browser data in issues. Use GitHub's private vulnerability-reporting feature if the repository enables it. Otherwise report only a non-sensitive summary and ask the maintainer for a private channel.

This review candidate has not undergone an independent security audit. DOM/audio mocks are not a substitute for real browser testing.
