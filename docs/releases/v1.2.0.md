## HDROLED v1.2 — Lighter

The simple manual edition for YouTube: choose your picture and sound levels, enable either effect, then watch. **Made by Harsh Mohan Sahani, made with Codex.**

### Included

- Separate display/video and sound switches, manual opacity/sound sliders and one Show original comparison.
- Fuller bass, dialogue-presence EQ, compression/gain and peak control on supported audio.
- Compact dark toolbar interface and static monitor/sound icon.
- Efficient single-pass page grading and one media scan per status request in the automated harness.
- No automatic performance sampler or automatic level changes. Preferences apply across YouTube tabs in the browser profile.

Lighter has fewer moving parts than Featured; this is not a measured CPU-saving guarantee. For movable controls, true 0.1% levels, independent video settings and automatic quality handling, choose [v2.0 Featured](https://github.com/harsh-mohan-99/hdroled-youtube/releases/tag/v2.0.0).

### Download and install

- **HDROLED-1.2-Lighter-Chromium.zip:** Chrome, Edge, Brave, Opera or Vivaldi. Extract → Developer mode → Load unpacked.
- **HDROLED-1.2-Lighter-Firefox.zip:** Firefox 140+ temporary installation through about:debugging. Unsigned; permanent installation requires Mozilla signing.
- Install one edition at a time and refresh YouTube after installation/update. [Full tutorial](https://github.com/harsh-mohan-99/hdroled-youtube/blob/main/INSTALL.md).

20 local automated checks passed. CI verifies tests, source and package checksums before publishing. Live cross-browser viewing/listening is a separate check. Browser-local YouTube colors/audio only; no power-management, system or driver changes. SDR appearance effect, not genuine HDR or physical OLED blacks.
