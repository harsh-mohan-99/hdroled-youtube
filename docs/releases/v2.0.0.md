## HDROLED v2.0 — Featured

More control while you watch YouTube. **Made by Harsh Mohan Sahani, made with Codex.**

### New in Featured

- Click the typographic HDROLED logo to open movable controls over YouTube, without another browser window.
- True0.1% picture/sound adjustment. The active picture slider stays visible while the other controls fade.
- Independent settings per tab/video; current titles follow navigation. Stale edits cannot replace a newer video's choices.
- Hardware-hint starting levels, small proportional adjustments after sustained slowdown, and gradual recovery toward the initial quality target after healthy playback.
- One Auto optimization button; manual choices take priority. No preset picker.
- Clean graphics name when exposed; unavailable hardware rows stay hidden. Clear display resolution.
- Opening bypasses pending setting saves. Toolbar reconnection and close/reopen races are covered by regression checks.

Prefer simpler manual controls without playback sampling? [v1.2 Lighter stays available](https://github.com/harsh-mohan-99/hdroled-youtube/releases/tag/v1.2.0). [Compare editions](https://github.com/harsh-mohan-99/hdroled-youtube#pick-your-edition).

### Download and install

- **HDROLED-2.0-Featured-Chromium.zip:** Chrome, Edge, Brave, Opera or Vivaldi. Extract → Developer mode → Load unpacked.
- **HDROLED-2.0-Featured-Firefox.zip:** Firefox 140+ temporary installation through about:debugging. Unsigned; permanent installation requires Mozilla signing.
- Disable older copies, load this edition and **refresh existing YouTube tabs**. Click the playing video once if sound needs activation. [Full tutorial](https://github.com/harsh-mohan-99/hdroled-youtube/blob/main/INSTALL.md).

41 local automated checks passed. CI verifies both editions, source/package contents and checksums before publishing. UI screenshots use simulated playback/hardware; live cross-browser viewing/listening remains separate.

Percentages describe effect strength, not measured speed gains. No PC-wide CPU/GPU monitoring or50% CPU gate. No power-management, system, HDR-mode, volume or driver changes. The SDR effect cannot create physical OLED blacks or genuine HDR.
